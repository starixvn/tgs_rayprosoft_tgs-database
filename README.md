# tgs-database

##  Create your database and schema

**1. ~\tgs-database\MigrationArchive**
```sh
dotnet ef database update
```
**2. ~\tgs-database\MigrationEntry**
```sh
dotnet ef database update
```
**3. run TgsSeeding**

## Migrations

** add/alter/delete/drop
```sh
dotnet ef migrations add {name}
```
